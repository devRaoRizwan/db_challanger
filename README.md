# DB Journey: Query it. Explain it. Own it.

A 40-day, ~35 min/day hands-on PostgreSQL course for backend developers.
Every exercise runs against **real Postgres 18 in your browser** (PGlite) and is checked automatically.

- Start: **Tue 27 Oct 2026** → Day 40: Sat 5 Dec 2026
- Progress is saved in your browser (localStorage). No locked days.

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173
npm run validate   # runs every example + solution against Postgres
```

Deploy: push to GitHub and import into Vercel as a static site (no build command, output = repo root).

To practice on a local Postgres instead: `psql -f seed.sql`.

## Daily session (~35 min)

| Min | Block | What you do |
|---|---|---|
| 5 | Learn it | Short written explanation with row-level pictures |
| 5 | See it | Run and tweak a worked example |
| 20 | Do it | 4–7 auto-checked exercises + quick quiz |
| 5 | Own it | 1–3 LeetCode SQL problems + explain-it note |

## Writing a day

Each day is `content/days/dNN.js` exporting one object. See `d01.js` and `d12.js` as references.

```js
export default {
  day: 7, phase: 1,
  title: 'Short title',
  goal: 'One sentence: what you can do after today.',
  setup: `optional SQL run after the seed when this day opens (e.g. a big table for index days)`,
  learn: `HTML string`,                 // ~300–600 words, plain English, show rows
  example: { sql: '...', note: '...' }, // runnable, rolled back after running
  exercises: [
    { id: 'd7-e1', type: 'query', prompt: 'HTML', hint: 'HTML', solution: 'SQL',
      ordered: false,      // true → row order is graded (solution must ORDER BY)
      check: 'SELECT ...', // optional: for DDL/DML — run after the user's SQL, its result is graded
      alts: ['SQL'],       // other correct answers (validated to pass)
      wrong: [{ sql: 'SQL' }], // classic mistakes (validated to FAIL)
      allowEmpty: false,   // true if the correct answer is 0 rows
      why: 'HTML: why the solution works' },
    { id: 'd7-q1', type: 'quiz', prompt: 'HTML', options: ['a','b','c'], answer: 1, why: 'HTML' },
  ],
  leetcode: [{ id: 175, title: 'Combine Two Tables', slug: 'combine-two-tables', difficulty: 'Easy' }],
  ownIt: 'An "explain it in your own words" prompt.',
};
```

**Grading:** your result is compared with the solution's result. Column **names are ignored**, but column
count, values and row count must match, and row order matters only when `ordered: true`. Numbers are compared
rounded to 2 decimals. Every run happens inside a transaction that is rolled back afterwards, so you can't
break the dataset.

**HTML available in lessons:** `<p> <h4> <ul> <ol> <code> <pre><code> <b> <i>`,
`<table class="mini">` (row pictures; `<td class="keep">` / `<td class="drop">` to highlight),
`<div class="callout">` (tip), `<div class="callout trap">` (common mistake),
`<div class="timeline">` + `<table class="mini">` for two-session transaction timelines.
